DESIGN

System Overview

The Purplle Store Intelligence System processes CCTV footage from multiple cameras and generates operational insights.

Components

1. CCTV Video Input
2. YOLOv8 Person Detection
3. Event Generation Layer
4. Analytics Engine
5. Streamlit Dashboard

Workflow

CCTV Footage → Person Detection → Event Generation → Analytics → Dashboard

AI-Assisted Decisions

AI tools were used to accelerate development, generate documentation, assist with dashboard creation, and improve project structure. Final design decisions, implementation choices, and testing were performed manually.

Production Readiness

- Modular architecture
- Separate detection and dashboard modules
- Support for multiple cameras
- Event-driven analytics design
